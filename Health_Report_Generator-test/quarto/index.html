How the reports are made

  1. FetchFOPH surveillance exports
  2. SnapshotRaw files archived with checksums
  3. HarmoniseAll datasets into one table
  4. Quality gateBlocking checks before analysis
  5. ReportOne Quarto report per audience

Every report ends with a Provenance section recording the source data, checksums, code version, tools and report parameters.

Source: FOPH open surveillance data. This is a hackathon prototype, not an official FOPH publication. Reported cases depend on testing and reporting and are not a count of all infections.
