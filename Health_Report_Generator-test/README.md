# Historical Quarto prototype

This directory contains an earlier standalone prototype for researcher and public-health reports, including committed HTML/PDF renders and provenance examples. It is not invoked by the current `Snakefile`, the default validation workflow, or the selected-report workflow.

The files are retained temporarily as design and implementation history. They must not be presented as outputs of the current production pipeline or used as evidence that the current build passes.

A later cleanup may archive or remove this directory after useful report content has been compared with the shared parameterized report source.
