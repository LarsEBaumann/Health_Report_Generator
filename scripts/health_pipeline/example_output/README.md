# Historical example outputs

Files in this directory are preserved examples from an earlier pipeline prototype. They are **not** generated by the current default Snakemake workflow and must not be used as release evidence, regression goldens, or proof of current reproducibility.

For supported outputs, run the workflow documented in the repository root and use the resulting stakeholder directory together with its matching `results/release.json`.

This directory may be archived or removed in a later, separately reviewed cleanup after confirming that no documentation or tests depend on it.
